---
name: scrum-theme
description: Switch the Scrum Studio website between dark and light appearance when the user requests an appearance change.
---

Use the website header's **Dark** or **Light** button in an available authorized browser. It toggles immediately and saves the preference in that browser; before a choice, the site follows the system preference. Verify the visible appearance after switching. If browser access is unavailable, explain where the button is rather than claiming to change it.

Theme is browser-local UI state, not project/task data. It has no MCP mutation and does not change another user's appearance. Do not edit the database or add AI polling for theme changes.
